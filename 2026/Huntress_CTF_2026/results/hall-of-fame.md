## What the fields establish

- **`elapsed_ms`** is explicitly a duration in milliseconds. Dividing by 1,000 produces the seconds shown above. It is a recorded ranked-attempt time, not a measure of the original investigation, solver development, total AI work, or all prior attempts.
- **`rank`** applies to one challenge and one mode. Every exported rank agrees with `1 + the number of strictly faster entries` on that board. Equal elapsed times share a rank, and the next position skips accordingly. Four team records are tied; none of the team's top-ten entries is tied.
- **`par_ms`** retains the source's label, *par*. The file does not define it as a hard server deadline. Par values vary within some boards, so the report does not assume identical parameters for all entrants.
- **`under_par_ms`** equals `par_ms - elapsed_ms` throughout the export. It is not research time saved or a measured improvement over a previous run.
- **`answer_count`** is preserved as the source's integer field. It should not be read as that many distinct named challenges, flags, exploits, or participants. The export does not fully define its counting rules.
- **Capture time** dates the snapshot. Individual rows have no attempt IDs or attempt timestamps, so this file cannot reconstruct the team's timing improvements over the month or identify a particular historical run conclusively.

The earlier [scoring-event CSV](team-scoring-events.csv) records when points were awarded. The [partial first-solve notes](partial-first-solve-notes.csv) record clock observations. The Hall of Fame file adds a separate kind of evidence: elapsed durations with ranks. These fields should remain distinct.

## Coverage and source limits

The file lists 186 daily challenges and two modes, giving 372 possible challenge/mode combinations. Rows are present for **178 Time Trial boards** and **177 Mastery boards**: **355 boards and 28,492 total entries**. Seventeen combinations have no exported rows.

All ranks are internally consistent; apparent position gaps are explained by tied elapsed times. The largest exported boards contain 264 Time Trial entries and 241 Mastery entries, so there is no evident fixed 100- or 200-row cap. However, the file provides no pagination, eligibility, deletion-history, or finalization metadata. It cannot establish that every eligible result was exported or explain missing rows.

The non-daily extras—Read the Rules, Welcome Robots, SHA1-Hulud, and Sanity Check—are outside this 186-challenge Hall of Fame catalog. This file does not supply an official combined Hall of Fame ranking across challenges. No new overall rank is calculated here.
