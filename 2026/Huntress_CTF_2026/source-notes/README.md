The later archive contains 127 files under its original `writeups/` folder across 28 day folders. Some days use combined progress notes. This file count is not a count of complete, independently reproducible walkthroughs.

Private lab IPs were replaced with the documentation address `192.0.2.1`. Session-specific artifact download capabilities were removed. Links to unavailable artifacts or original VM paths were changed to labeled historical references. Historical `AGENTS.md` files were renamed `workflow-instructions.md` so they remain evidence rather than active repository instructions. The [manifest](../source-manifest.json) identifies every selected source and published file by hash.

The original connection document contained a Game Master pairing credential and is excluded. Local Git metadata, connection configuration, cached files, copied organizer onboarding pages, and challenge specimens are excluded as well. The [exclusions list](../source-exclusions.json) explains omitted source paths. Specimens supplied in the archives are listed in the [artifact inventory](../source-artifact-inventory.csv); an inventory entry establishes that bytes were supplied, not that redistribution rights were established or that a missing later artifact can be recovered.

For SHA1-Hulud, read the later successful-session account before the early handoff notes. In particular, the older “irreversible KDF” conclusion was superseded. Historical claims that companion files or complete logs existed describe the original analysis session; those files were not present in these uploads.

Many documents refer to `work/` or `attempt-records/` folders that were not included. The prose remains available, but those missing records cannot be recreated from a filename or a completion claim. The curated writeups distinguish saved artifacts, saved state, historical claims, and missing evidence.
