# Complete challenge catalog

[Event overview](../README.md) · [Results and scoring evidence](../results/README.md) · [Index by article](ARTICLE_INDEX.md)

The saved scoreboard contains **190 named tasks**: 186 daily challenges, three scored extras, and unscored Sanity Check. They are mapped below to **172 editorial records**. Thirteen release-day Web articles group all 31 Web tasks; the other daily lanes have one record per day.

All 186 daily challenges have recorded Single Solve, Time Trial, and Mastery scoring awards (558 awards / 1,860 points). Read the Rules, Welcome Robots, and SHA1-Hulud add three awards / 25 points, for **561 awards / 1,885 points**. Sanity Check has no numeric award. These facts establish scoring coverage, not that every complete solving transcript survived.
